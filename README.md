# FTSM Internship FAQ — Semester 1, 2026–2027

A mobile-friendly, standalone FAQ page. Includes keyword search, expandable answers, start deadlines and email links. All styling and JavaScript are in index.html. No installation or build is required.

## Preview
Double-click index.html to open it in your browser.

## Publish using GitHub Pages (no terminal required)
1. Sign in at https://github.com/.
2. Click the + menu, then New repository.
3. Name the repository internship-faq and select Public. Click Create repository.
4. On the new repository page, click uploading an existing file. If the repository already has files, choose Add file > Upload files.
5. Upload the extracted index.html and README.md files, not the ZIP or the enclosing folder. index.html must be at the top level of the repository.
6. Enter a commit message such as Add internship FAQ, then click Commit changes.
7. Open Settings > Pages.
8. Under Build and deployment, set Source to Deploy from a branch.
9. Choose main and /(root), then click Save. If your repository uses another default branch, select that branch instead.
10. Wait for the deployment to finish. Refresh Settings > Pages and open the displayed site link. The usual project address is https://YOUR-USERNAME.github.io/internship-faq/.

## Update the FAQ
Open index.html in your GitHub repository, click the pencil icon and edit the relevant question in <summary> or its answer in <div class="answer">. Commit the change to the publishing branch. GitHub Pages will publish the update automatically.

## If you see a 404 error
Check that index.html is in the repository root, that Pages uses the correct branch and /(root), and that the latest deployment succeeded in the Actions tab.
